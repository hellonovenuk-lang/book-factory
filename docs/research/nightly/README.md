# Nightly book proposals

Three nights a week a scheduled routine (a job Claude runs on its own) researches the
next book Book Factory should make and writes one proposal here, following
`.claude/skills/nightly-book-research/SKILL.md`. Kieran reads it in the
morning and replies `go` or `no` in that night's session (claude.ai/code).

Rules for the routine: it only researches and writes proposals. It never
creates a book, spends picture credits, approves anything or publishes.

Angles rotate: 1 Dave series, 2 new format for the same buyers, 3 a new line.
