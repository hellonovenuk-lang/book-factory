The test run
A test run is a short, cautious attempt to assess recovery.

  It is not twelve miles with a faster final section.

  Before leaving, state the maximum duration aloud to Sam.
Return at that time. If pain appears, stop. Do not negotiate
with the pain using promises about pace.

  Afterwards, describe the outcome once.

  Alex’s first test run lasted 74 minutes because the calf
‘needed enough data’. Dr Hughes requested a second
opinion from the calf.
